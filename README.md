📚 PageVault Pro – OpenShelf Campus Exchange

Presented By: G. Karthik

About Project

PageVault Pro is a student-powered book-sharing platform that allows students to list, search, borrow, and exchange academic textbooks easily.

Features

- Student Registration and Login
- Add and Search Books
- Borrow Book Requests
- Book Availability Status
- Student Dashboard
- Wishlist Management

Technologies Used

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- MongoDB

How to Run

npm install
npm start

Open: "http://localhost:5000"

Objective

To reduce textbook expenses and encourage knowledge sharing among students.
